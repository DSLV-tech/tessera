# Asset di brand — Tessera

- `mark.svg` — il marchio: una tessera composta da sei tessere, una per modalità
  (dominio · oro, assedio · verde-acqua, bersaglio · vino, sigilli · viola,
  ponti · blu, simmetria · rosa).
- `logo-horizontal.svg` — lockup orizzontale (marchio + wordmark + tagline).
- `logo-stacked.svg` — lockup verticale.

Il wordmark usa un serif display con gradiente avorio→oro. I colori delle sei
modalità sono definiti in `src/styles/tokens.css` (`--mode-*`).
Le icone PWA in `public/` (icon-192/512, apple-touch-icon) sono rasterizzate dal marchio.
